# Web de Juerga OS

Abre `index.html` en un navegador. Todos los archivos de la web están en esta carpeta. Las fuentes se cargan desde Google Fonts si hay conexión; si no, se utilizan fuentes del sistema.

El botón de descarga aún no hace nada, como se solicitó. Cuando exista una imagen oficial, sustituye el botón y su controlador en `script.js` por un enlace al archivo publicado y actualiza el mensaje de disponibilidad.

Las estadísticas y opiniones visibles son ejemplos ficticios claramente identificados; para publicar datos auténticos sustitúyelos por cifras y opiniones verificadas. El 0,2 % de 147 no es un número entero de personas, por lo que las cifras de ejemplo no representan una muestra coherente.

La imagen del escritorio procede de una sesión experimental aislada de Juerga OS; la franja de avisos de prueba está atenuada en la presentación y no representa una instalación completa.
